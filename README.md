# WorldCards 🌍

> Интерактивное веб-приложение для изучения стран и столиц мира в формате карточек и мини-тестов.

## Возможности

- карточки стран: флаг, название, столица и факт;
- свайпы для оценки знания и прогресс изучения;
- режим повторения с вопросами «страна → столица», «флаг → столица» и «столица → страна»;
- ввод ответа, проверка похожести, подсказки и серия правильных ответов;
- статистика изучения и ошибок;
- экспорт и импорт прогресса в JSON;
- светлая/тёмная тема, звук, громкость и вибрация.

## Технологии

- HTML5
- CSS
- Vanilla JavaScript / ES Modules
- LocalStorage
- Web Audio API
- Vibration API
- Web App Manifest

Прогресс пользователя хранится локально в браузере; backend для основной логики не требуется.

## Структура


## Запуск

Это статическое приложение. Для локального запуска:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

Проект также подходит для размещения на GitHub Pages.
