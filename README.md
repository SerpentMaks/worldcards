# WorldCards

PWA для изучения стран и столиц мира.

## Возможности

- карточки стран;
- ввод ответа;
- подсказки;
- статистика и серия правильных ответов;
- импорт и экспорт JSON;
- темы оформления;
- звуки и вибрация;
- установка как PWA.

## Стек

- HTML
- CSS
- JavaScript
- Web App Manifest
- Service Worker

## Запуск

Проект можно открыть как статический сайт или разместить на GitHub Pages.

## Статус

🟢 Самостоятельный веб-проект для обучения.
